The 2 Foundation Pillars

Two Specialized Engines, One Ecosystem

Clean separation between the high-level business component orchestrator and the low-level universal DOM tag compiler.

Pillar 01 • High-Level Runtime 🖥️

json-renderers

The Component Orchestrator. Accepts raw business data, columns (the story about the data), and type (the component intent). Coordinates contract validation, headless spec compilation, and DOM placement.

What It Delivers:
  • Composite Tables: Automated # serials, numeric alignment, and footer totals in <tfoot>.
  • Autocomplete Datalists: Native HTML5 <datalist> without external JS widgets.
  • Select Dropdowns & Forms: Declarative options binding and schema controls.
  • The House-Building Story: Conceptual mental model in subDoc/.
Explore json-renderers Suite → Open subDoc Hub →
Pillar 02 • Low-Level Compiler ⚙️

json-to-tag

The Universal DOM Compiler. A zero-dependency engine that transforms declarative JSON specifications into real native HTML DOM elements via recursive specification traversal.

What It Delivers:
  • Recursive Traversal: Visits nested parent-child trees handling objects, arrays, and text.
  • Zero Virtual DOM: Direct synthesis via native document.createElement().
  • HTML Tag Catalog: Comprehensive JSON catalog of supported HTML5 tags.
  • Independent Utility: Can be used standalone in any project without renderers.

Quick Start in 10 Seconds

Add to any HTML page via CDN

No bundler, build step, or node_modules required. Import the ES module directly in your browser: 

<!-- 1. Target Container -->
<div id="my-table"></div>

<!-- 2. Single Script Import & Render -->
<script type="module">
  import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v18/min.js";

  render({
    type: "table.withFooter",
    columns: ["item", "qty", "amount"],
    data: [
      { item: "High Tensile Rope", qty: 25, amount: 3000 },
      { item: "Agri Shading Net",  qty: 10, amount: 1250 }
    ],
    targetHtmlId: "my-table"
  });
</script>
