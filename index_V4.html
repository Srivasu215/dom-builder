A simple story

json-renderers Ecosystem

Build UI from JSON: define the structure, connect it to a target element, and render the result as native HTML. When you want to build a configured component from a render request, you supply a component type, data, columns when needed, and a targetHtmlId. The renderer orchestrates validation, headless blueprint compilation, and direct DOM synthesis.

The main idea

Describe what you want to display

Imagine you have a list of products and want to show them in a table. Instead of manually creating every table row, setting styles, and concatenating strings, you send json-renderers a request describing the component, the data, the columns, and the HTML element where the result should appear.

Example

Build a table from data via CDN

This request displays two product rows in a table and places the result inside my-table.

<div id="my-table"></div>

<script type="module">
  import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v18/min.js";

  render({
    type: "table.withFooter",
    columns: ["item", "qty", "amount"],
    data: [
      { item: "Rope", qty: 25, amount: 3000 },
      { item: "Net",  qty: 10, amount: 1250 }
    ],
    targetHtmlId: "my-table"
  });
</script>
Field meanings:
• type selects the component.
• columns defines the table fields and alignments.
• data supplies the row values.
• targetHtmlId identifies where to render the result.
