The Reality Check

The 4 Struggles of Writing Real-World HTML

HTML looks simple in textbooks. But in real-world data-driven applications, it quickly becomes an unmaintainable burden.

Pain Point 01
Writing Correct HTML is Tough

Nested string concatenation and manual document.createElement trees are verbosely repetitive, hard to read, and prone to unclosed tags and typos.

Pain Point 02
Composite Controls are Complex

A real Table isn't just <table>. It's thead, tbody, tfoot, row serials (#), column alignments, and calculated totals. A Form requires complex input-groups and datalists.

Pain Point 03
Classes & Theming are Painful

Sprinkling Bootstrap classes across dozens of <th>, <td>, and <input> tags is exhausting. Changing to Dark mode means modifying hundreds of class names manually!

Pain Point 04
Attributes Require Deep Boilerplate

You must remember and wire endless attributes: colspan, type="number", align="right", list="id", id, name, and placeholder. Miss one and UI breaks.

The Great Contrast

How We Made It Simple

Look at the difference between handwriting raw composite HTML versus declaring clean, portable JSON.

❌ THE RAW HTML NIGHTMARE 100+ Lines of Verbose Tags

Manual nested tags, repeated classes on every cell, hardcoded attributes, and error-prone footer calculations: 

<!-- Hundreds of lines of brittle markup -->
<table class="table table-striped table-hover align-middle">
  <thead class="table-light border-bottom">
    <tr>
      <th class="text-center" scope="col">#</th>
      <th scope="col">Product Name</th>
      <th class="text-end" scope="col">Amount</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td class="text-center">1</td>
      <td>ROPE 10MM</td>
      <td class="text-end">1,200.00</td>
    </tr>
    <!-- Repeat <tr> and classes for every row... -->
  </tbody>
  <tfoot class="table-light border-top fw-bold">
    <tr>
      <td colspan="2">Total</td>
      <td class="text-end">1,200.00</td>
    </tr>
    <!-- Manual tax rows and grand totals... -->
  </tfoot>
</table>
✅ THE DECLARATIVE JSON BREAKTHROUGH Clean • Reusable • Config-Driven

You declare your data, columns, and calculations. The system handles all tag nesting, styling, and attributes: 

// Just provide pure JSON!
const table = new Table({
  inData: [{ item: "ROPE 10MM", amount: 1200 }],
  inColumns: [
    { key: "item", label: "Product Name" },
    { key: "amount", label: "Amount", type: "number", align: "right" }
  ],
  inConfig: {
    serial: true, // Automatically creates '#' serials
    foot: [
      { id: "total", title: "Total", type: "aggregate", values: { amount: "sum" } },
      { id: "tax", title: "GST (18%)", type: "eval", values: { amount: "total.amount * 0.18" } }
    ]
  },
  inTargetContainerId: "table-container"
});

table.render(); // Instantly compiled to native DOM!
