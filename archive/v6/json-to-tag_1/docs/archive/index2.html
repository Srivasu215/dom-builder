JSON to Tag

Turn declarative JSON specifications into native HTML DOM elements.

A zero-dependency JavaScript library from KeshavSoft for building DOM elements from JSON and reviewing specifications against an HTML tag catalog.

npm Package Step-by-Step Guide HTML Tags Catalog Specification Summary

Quick Start

Install the package:

npm install @keshavsoft/json-to-tag

Describe an HTML element using a JavaScript object:

import { buildSpecElement } from "@keshavsoft/json-to-tag";

const spec = {
  tagName: "button",
  textContent: "Submit",
  classList: "primary-button",
  attributes: { type: "button" }
};

const element = buildSpecElement({ inSpec: spec });
document.body.appendChild(element);

How It Works

  1. Define the desired HTML structure as a JSON-compatible specification.
  2. Pass the specification to buildSpecElement({ inSpec }).
  3. Receive a native DOM element and attach it to the document.

Review a Specification

Use reviewSpec({ inSpec }) to inspect tag usage and identify tags that are not recognized by the catalog.
