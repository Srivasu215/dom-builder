Tier 1 • High-Level Component Engine

json-to-dom-renderers

The High-Level State & JSON-to-JSON Transformer. It ingests business data, calculates totals and GST formulas, profiles autocomplete frequencies, and generates pure element specifications without direct DOM mutation.

Interactive Live Demo Repository
Table

Auto serial rows (#), multi-tier aggregates (sum, avg), evaluated formulas (GST * 0.18), and surgical repainters.

Form

Schema-driven filter and entry forms matching column definitions with interactive control-tree indexing (pruneTreeWithIds).

DataList

HTML5 autocomplete profiling with count badges (e.g. ROPE (3)) and topN caps to keep DOM footprint lean.

DataProvider

Decoupled CRUD repository adapter pattern. Manages REST URLs, headers, and async operations with zero auth coupling in UI.

Production Code Recipes (Strict in/local Convention) 
import { Table } from "https://cdn.jsdelivr.net/gh/keshavsoft/json-to-dom-renderers/docs/dist/v12/min.js";

const table = new Table({
    inData: records,
    inColumns: columns,
    inTargetContainerId: "table-box",
    inConfig: {
        serial: true,
        row: { striped: true, hover: true },
        foot: [
            { id: "subTotal", title: "Sub Total", type: "aggregate", values: { amount: "sum" } },
            { id: "taxRow", title: "GST (18%)", type: "eval", values: { amount: "subTotal.amount * 0.18" } },
            { id: "grandTotal", title: "Grand Total", type: "eval", values: { amount: "subTotal.amount + taxRow.amount" } }
        ]
    }
});

table.render();
import { Form } from "https://cdn.jsdelivr.net/gh/keshavsoft/json-to-dom-renderers/docs/dist/v12/min.js";

const form = new Form({
    inColumns: columns,
    inConfig: { body: { columns: ["item", "category"] } },
    inTargetContainerId: "filter-box"
});

const { treeWithIds, spec, element } = form.render();
import { createDataProvider, Table } 
    from "https://cdn.jsdelivr.net/gh/keshavsoft/json-to-dom-renderers/docs/dist/v12/min.js";

const provider = createDataProvider({
    inReadUrl: "https://api.example.com/items",
    inCreateUrl: "https://api.example.com/items",
    inUpdateUrl: "https://api.example.com/items/:id",
    inDeleteUrl: "https://api.example.com/items/:id",
    inHeaders: { "Authorization": "Bearer SECURE_TOKEN" }
});

const table = new Table({ inColumns: columns, inDataProvider: provider });
await table.load();
