Why Declarative? The Comparison

Compare writing manual imperative DOM code vs declaring pure JSON.

Imperative HTML / Vanilla DOM (Tedious) 
// 30+ lines of verbose imperative DOM manipulation
const tbl = document.createElement("table");
const thead = document.createElement("thead");
const headerRow = document.createElement("tr");

["Item", "Qty", "Price"].forEach(col => {
  const th = document.createElement("th");
  th.textContent = col;
  headerRow.appendChild(th);
});
thead.appendChild(headerRow);
tbl.appendChild(thead);

// Manual loops for rows, totals, formatting...
// Manual event listeners, class assignments...
// Fragile, repetitive, hard to maintain.
KeshavSoft Declarative JSON (Simple) 
// Pure declarative JSON — 6 clean lines:
render({
  type: "table.withFooter",
  columns: ["item", "qty", "amount"],
  data: records,
  targetHtmlId: "target-container"
});

// That's it! 
// Headers, rows, calculated footers, alignments, 
// and DOM mounting happen automatically.

How It Works: The 3-Tier Pipeline

Clean separation of concerns with zero virtual DOM overhead.

1
Your Data & Columns

Pass your raw JSON arrays and simple column names straight from your backend API or store.

2
Spec Compiler

json-renderers-build compiles blueprints for tables, footers, datalists, and select menus.

3
Fast DOM Mount

@keshavsoft/json-to-tag translates the blueprint into real browser elements and mounts them.

Quick Start in 10 Seconds

Add to any HTML page via CDN

No bundler, build step, or node_modules required. Just import the ES module directly in your browser: 

<!-- 1. Target Container -->
<div id="my-table"></div>

<!-- 2. Single Script Import & Render -->
<script type="module">
  import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v18/min.js";

  render({
    type: "table.withFooter",
    columns: ["name", "role", "city"],
    data: [
      { name: "Rajesh", role: "Architect", city: "Bengaluru" },
      { name: "Anita", role: "Engineer", city: "Hyderabad" }
    ],
    targetHtmlId: "my-table"
  });
</script>
