The Composite Form

How we solved the form struggle: Generating input groups matching column schemas, automatic HTML5 <datalist> autocomplete linking, and friction-free control-tree event wiring.

1. Input Groups from Schemas

Declare "body": { "columns": ["item", "category"] }. The renderer builds all input groups, placeholders, and action buttons matching the column metadata.

2. Automatic DataList Wiring

DataList analyzes your dataset, computes frequency counts, and attaches list="id" to input elements automatically.

3. Controls Tree Indexing

form.getControlsTree() extracts an indexed tree of elements with assigned IDs, allowing you to attach event listeners without searching the DOM.

Declarative Form & DataList Code 
import { Form, DataList, Table } 
    from "https://cdn.jsdelivr.net/gh/keshavsoft/json-to-dom-renderers/docs/dist/v12/min.js";

// 1. Generate Form for specific columns
const form = new Form({
    inColumns: columns,
    inConfig: { body: { columns: ["item", "category"] } },
    inTargetContainerId: "form-container"
});
const { treeWithIds, spec, element } = form.render();

// 2. Generate Autocomplete DataList with frequency profiling
const dataList = new DataList({
    inData: data,
    inColumns: columns,
    inConfig: { datalist: { columns: ["item", "category"] } },
    inTargetContainerId: "datalist-container"
});
dataList.render();

// 3. Attach click listeners to form buttons
element.querySelectorAll("button").forEach(btn => {
    btn.addEventListener("click", e => {
        const row = e.currentTarget.closest("div");
        const input = row.querySelector("input");
        table.filterStateData({ query: { [input.name]: input.value } });
        dataList.update({ data: table.store.stateData });
    });
});
