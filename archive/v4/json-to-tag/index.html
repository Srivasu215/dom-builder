JSON to Tag

Describe your HTML as JSON. Let the library build the DOM.

JSON to Tag is a JavaScript library that transforms declarative JSON specifications into native HTML DOM elements.

Why JSON to Tag?

Every web interface ultimately becomes a Document Object Model (DOM). Traditionally, developers describe that interface using HTML markup or construct it programmatically with JavaScript.

HTML markup

Requires knowledge of HTML tags, nesting, opening and closing tags, and attributes.

JavaScript DOM APIs

Provides programmatic control, but requires repeated element creation, attribute setting, and child insertion.

JSON to Tag

Describe the intended structure as data and let the library create the corresponding DOM elements.

The idea

JSON already represents structured information using familiar objects, keys, arrays, and values. A UI can also be described as structured information: which tag to create, what text it contains, which attributes it needs, and which children belong inside it.

Native HTML DOM elements

Why this matters

  • Keep UI structure separate from the code that builds it.
  • Generate specifications programmatically or reuse existing JSON data.
  • Make UI structures easier to inspect, modify, share, and process with JSON tools.
  • Reuse one DOM-building library instead of repeatedly writing element-construction code.

What the library provides

buildSpecElement() builds DOM elements from a specification. The repository also provides specification-review functionality and an HTML tag catalog.

Get started

npm install @keshavsoft/json-to-tag

Explore the README for the documented API and examples, and the docs/tags/tags.json catalog for supported tag definitions.
