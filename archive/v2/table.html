The Composite Table

How we solved the struggle of table markup: Automated row serials (#), column alignments, multi-tier footer aggregates (sum), evaluated tax formulas, and instant theme switching.

1. Row Serials (#)

Just set "serial": true in config. The table automatically prepends indexed serial cells to head, body, and foot.

2. Alignments & Types

Define align: "right" or type: "number" in column schemas. The renderer automatically injects text alignment classes.

3. Formulas & Sums

Multi-tier footers compute aggregates ("sum") and eval formulas (e.g. subTotal.amount * 0.18) dynamically.

4. Zero-Friction Theming

Classes come from classes.json catalogs. Switch to Dark or Light with a single method call: .setTheme().

The Entire Table Declaration (Pure JSON) 
import { Table } from "https://cdn.jsdelivr.net/gh/keshavsoft/json-to-dom-renderers/docs/dist/v12/min.js";

// 1. Column Schemas (Types & Alignments)
const columns = [
    { key: "item", label: "Product Name" },
    { key: "category", label: "Category" },
    { key: "qty", label: "Quantity", type: "number", align: "center" },
    { key: "amount", label: "Amount (₹)", type: "number", align: "right" }
];

// 2. Declarative Config (Serials, Hover, Aggregates & Formula Footers)
const config = {
    serial: true,
    row: { striped: true, hover: true },
    foot: [
        { id: "subTotal", title: "Sub Total", type: "aggregate", values: { amount: "sum", qty: "sum" } },
        { id: "taxRow", title: "GST (18%)", type: "eval", values: { amount: "subTotal.amount * 0.18" } },
        { id: "grandTotal", title: "Grand Total", type: "eval", values: { amount: "subTotal.amount + taxRow.amount" } }
    ]
};

// 3. Render Table
const table = new Table({
    inData: records,
    inColumns: columns,
    inConfig: config,
    inTargetContainerId: "table-container"
});

table.render();
