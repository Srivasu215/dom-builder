Struggle 01 of 05 • The Reality

Writing Correct HTML is Tough

Tutorials make HTML look trivial with simple paragraphs and buttons. In real business applications, handwriting correct markup is a massive, error-prone chore.

Why It Breaks in Practice:
  • String Concatenation Hell: Constructing HTML via JS string templates leads to XSS bugs, unclosed tags, and syntax errors.
  • Verbose DOM Calls: Calling document.createElement for deeply nested trees requires dozens of lines for a single element.
  • Zero Type Safety: Any typo in a tag name or hierarchy silently breaks the layout.
// The Verbose DOM Creation Nightmare const table = document.createElement("table"); const thead = document.createElement("thead"); const tr = document.createElement("tr"); const th1 = document.createElement("th"); th1.textContent = "Item Name"; tr.appendChild(th1); thead.appendChild(tr); table.appendChild(thead); // ...Repeat 80 more times just for headers & rows!
Struggle 02 of 05 • Structural Complexity

Composite Controls are Complex

Business interfaces don't use primitive tags — they require Composite HTML Controls like Tables and Forms.

The Real Anatomy of a Table

A Table isn't just <table>. It requires a complete nested tree:

  • <thead> with columns, data-type alignments (left, center, right).
  • Automatic row numbering / serials (#).
  • <tbody> with dynamic records.
  • <tfoot> with multi-tier aggregates (sum) and calculated tax formulas (GST 18%).
The Real Anatomy of a Form

A real Form requires sophisticated layout components:

  • Nested input-group containers with labels.
  • Inline filter action buttons.
  • Linked HTML5 <datalist> controls for autocomplete.
  • Control-tree ID tracking for wiring event listeners.
Struggle 03 of 05 • Theming & Classes

Classes & Theming: Not a Small Thing!

Applying and updating CSS framework classes across hundreds of generated elements is one of the most tedious tasks in frontend development.

The Hardcoded Class Problem:

You have to write Bootstrap classes on every single element:

class="table table-striped table-hover align-middle table-sm border-secondary"

Want to switch to Dark Mode or Extra Light?
You have to touch and rewrite class names across hundreds of table cells and input tags!

How We Solved It with Catalogs:

We decoupled all classes into a single declarative JSON catalog (classes.json).

// Instant theme change in one call: table.setTheme({ inTheme: "dark" }); form.setTheme({ inTheme: "dark" });
