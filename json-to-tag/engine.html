Tier 2 • Low-Level Compiler Engine

json-to-dom

The Declarative JSON-to-DOM Compiler. It has zero domain knowledge of tables or business vouchers. Its sole responsibility is translating a pure JSON element specification into native browser DOM nodes with blistering speed.

Try Live Spec Compiler Repository

The Architectural Boundary

In KeshavSoft's architecture, json-to-dom represents the physical boundary crossing:

// The One-Line Boundary Crossing:
const domElement = window.ks["json-to-dom"].buildSpecElement({ inSpec });
  • Input: Declarative JSON Specification (inSpec).
  • Recursion: Walks child nodes recursively, generating document.createElement.
  • Attributes: Sets attributes, adds class lists, maps inline styles, and attaches native event listeners.
  • Output: A real, living HTMLElement or DocumentFragment.
Spec Schema Keys:
KeyTypeDescription
tagNameStringHTML tag (e.g. "div", "table")
classListArrayCSS classes (e.g. ["alert", "alert-info"])
textContentStringInner text node content
attributesObjectDOM attributes (e.g. { id: "my-btn" })
childrenArrayNested array of child spec objects
