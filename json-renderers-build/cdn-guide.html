How to Build & Run with CDN

Zero build setup. Import the renderer directly from jsDelivr in any modern browser without npm or bundlers.

Copy & Run Template

Complete HTML Example

Save this as index.html and double-click to run in your browser:

index.html (30 Lines) 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>CDN Table Demo</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet" />
</head>
<body class="p-4">
  <h3>Live CDN Rendered Table</h3>
  <div id="my-table"></div>

  <script type="module">
    // 1. Direct CDN Import
    import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v14/min.js";

    // 2. Data & Columns
    const items = [
      { id: 1, item: "Electric Motor", qty: 12, price: 9500 },
      { id: 2, item: "Hydraulic Valve", qty: 6,  price: 4200 },
      { id: 3, item: "Steel Bearings",  qty: 50, price: 350 }
    ];

    // 3. Mount to DOM
    render({
      type: "table",
      targetHtmlId: "my-table",
      columns: ["id", "item", "qty", "price"],
      data: items,
      showLog: true
    });
  </script>
</body>
</html>
