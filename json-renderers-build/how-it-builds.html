How json-renderers-build Works

A fast functional pipeline that compiles raw records and column definitions into an abstract JSON DOM tree without touching the browser DOM.

Lifecycle

The 4-Step Compilation Pipeline

Step 01

Input Request

Receives type, data array, and columns array.

Step 02

Guard Validation

Runs guardSpec(config) from json-renderers-guard.

Step 03

Template Expansion

json-to-spec expands row loops and aligns numeric values.

Step 04

JSON AST Tree

Returns pure spec with tagName, attributes, and children.

Code Walkthrough (30 Lines)

Input Intent vs. Output Specification

Input: Render Request 
import render from "json-renderers-build";

// 1. Describe intent
const config = {
  type: "table",
  columns: ["item", "qty", "rate"],
  data: [
    { item: "Steel Wire", qty: 20, rate: 150 },
    { item: "Copper Rod", qty: 10, rate: 320 }
  ]
};

// 2. Compile to spec (Headless)
const spec = render(config);
console.log(spec);
Output: JSON Spec (AST)

Headless Architecture: Because json-renderers-build never calls document.createElement, it executes anywhere: Node.js (for SSR), Web Workers, or frontend browsers.
