Overview

How it is built

dom-builder documents how the two repositories work together. json-renderers receives the rendering request and prepares the blueprint for a component. json-to-tag uses the JSON tag structure to create the actual HTML elements. The target element ID connects the rendered result to the intended place in the page.

Responsibilities

What each repository does

json-renderers

Works at the component level: interprets the render request, uses the component blueprint, and coordinates preparation of the requested UI.

json-to-tag

Works at the DOM level: converts a JSON description of tags, attributes, text, and children into native HTML elements.

Together, they separate what UI is requested from how its HTML elements are created.

Example

Add to any HTML page via CDN

This example shows the kind of request used to ask json-renderers to build a table and place it in the element with ID my-table withFooter.

<!-- 1. Target Container -->
<div id="my-table"></div>

<!-- 2. Single Script Import & Render -->
<script type="module">
  import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v18/min.js";

  render({
    type: "table.withFooter",
    columns: ["item", "qty", "amount"],
    data: [
      { item: "High Tensile Rope", qty: 25, amount: 3000 },
      { item: "Agri Shading Net",  qty: 10, amount: 1250 }
    ],
    targetHtmlId: "my-table"
  });
</script>
In this example: type selects the component, columns describes the fields, data supplies the rows, and targetHtmlId identifies where the result should be mounted.
