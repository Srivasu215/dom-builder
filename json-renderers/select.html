Declarative Dropdowns

Accessible HTML <select> Dropdowns

Compile JSON options arrays and key-value maps directly into semantic, high-performance HTML dropdowns with zero boilerplate.

Two Rendering Modes Supported:
  • Full Select: type: "select" — builds both the outer <select> and all its inner <option> tags.
  • Options Only: type: "selectOptionsOnly" — populates options into an existing pre-styled select tag.
Declarative Code
// 1. Import render directly via CDN
import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v18/min.js";

// 2. Define your options array (or key-value objects)
const countries = [
  "India",
  "United States",
  "United Kingdom",
  "Germany",
  "Japan",
  "Australia"
];

// 3. Compile and mount into container
render({
  type: "select",
  data: countries,
  targetHtmlId: "dom-select-container",
  showLog: true
});

// 4. Attach event listener to the mounted select:
document.querySelector("#dom-select-container select")
  ?.addEventListener("change", (e) => {
    console.log("Selected:", e.target.value);
  });
How It Works Under The Hood
Layer Package Responsibility
1. Guard json-renderers-guard Validates type, data, and targetHtmlId.
2. Spec Builder json-renderers-build-options Transforms array into standard select / option JSON specs.
3. DOM Mount @keshavsoft/json-to-tag Creates real HTMLSelectElement nodes with zero framework overhead.
