json-to-tag

A simple story

Native DOM Synthesizer & Mount Engine

Every web interface ultimately becomes nodes in the browser's Document Object Model (DOM). json-to-tag is the low-level engine that interprets abstract JSON tag specifications and converts them into real, native HTML elements using standard browser APIs — without touching risky innerHTML string injection.

The Execution Chain: JSON Specification → json-to-tag → Native Browser HTML DOM.
Core Motivation

Why use JSON specifications to build DOM?

Building DOM elements manually with native JavaScript APIs usually requires hundreds of verbose, repetitive commands:

The Problem

Manual createElement is Verbose

Creating a table requires calling document.createElement("table"), then thead, tr, th, appending each child, setting classes, and wiring attributes line by line.

The Danger

innerHTML String Injection is Risky

Concatenating HTML strings is vulnerable to Cross-Site Scripting (XSS), breaks event listener bindings, and causes entire subtree re-parsing on every update.

The Solution

json-to-tag Tree Synthesis

Structures are described cleanly as JSON trees. json-to-tag recursively traverses the tree and safely creates authentic DOM nodes with high performance.

How It Works

Recursive DOM generation engine

When given a specification, json-to-tag follows a clean, recursive algorithm:

01

Instantiate the Element Node

Reads tagName (e.g., "div", "table", "input") and creates the real element via document.createElement(spec.tagName).

02

Assign Attributes & Classes

Iterates through the attributes map, applying standard HTML attributes (such as class, id, href, style, colspan) directly to the node.

03

Inject Text or Value Content

If a text property is present, a safe text node is created and appended: element.textContent = spec.text.

04

Recursively Mount Children

If a children array exists, the engine recurses for each child specification, attaching the resulting DOM nodes to the parent element before returning the completed tree.

Code Example

Transforming JSON spec into live DOM

Here is a concise example showing the input specification and the resulting native DOM: 

// 1. JSON Specification
const cardSpec = {
  tagName: "div",
  attributes: { class: "user-card" },
  children: [
    { tagName: "h4", text: "Product Catalog" },
    {
      tagName: "button",
      attributes: { class: "btn-primary", type: "button" },
      text: "View Details"
    }
  ]
};

// 2. Synthesize using json-to-tag
const domNode = buildElement(cardSpec);

// 3. Mount directly into container
document.getElementById("container").appendChild(domNode);
Result: A native <div class="user-card"><h4>Product Catalog</h4><button class="btn-primary" type="button">View Details</button></div> is constructed in memory and safely mounted into the DOM.
