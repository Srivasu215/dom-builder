json-renderers-build

Headless Specification Compiler: From Data to JSON Tag Trees

json-renderers-build is the headless compiler of the json-renderers ecosystem. When json-renderers receives a render request, it delegates the specification synthesis to this engine. It takes raw data records, column definitions, and UI blueprints — and compiles them into a pure, abstract JSON tag specification tree (AST) specifying the exact DOM hierarchy, attributes, and alignment.

How json-renderers Uses It: json-renderers coordinates the pipeline: it runs validation, calls json-renderers-build to get the abstract JSON specification, and hands that specification over to json-to-tag to mount live native HTML elements into targetHtmlId.

Core Dependencies

What powers json-renderers-build under the hood

json-renderers-build is designed with strict separation of concerns. It relies on a few key modular packages to execute its compiler tasks:

json-renderers-guard

Validates the incoming request contract (verifying compulsory fields like type and data) before compilation begins.

Component Archetypes

Modular builders (json-renderers-build-table, json-renderers-build-options) that provide layout rules and footer arithmetic.

Functional Transformation

Pure input to output in under 30 seconds

Because the builder is 100% headless (never accessing document or the window), it executes synchronously with blazing speed: 

import render from "json-renderers-build";

// 1. Send intent
const spec = render({
  type: "table",
  columns: ["item", "qty"],
  data: [{ item: "Copper Rod", qty: 50 }]
});

// 2. Returns pure JSON Tag Tree (specAsJsonToDom)
// Ready for json-to-tag or SSR rendering!
