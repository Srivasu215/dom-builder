Table Builds (Simple & withFooter)

Build high-performance, accessible enterprise data tables with automated serial indexing (#), right-aligned numerical columns, and calculated summary totals in <tfoot>.

Documentation • Part 1

Why Use json-renderers Table Builds?

Building tables in frontend applications usually requires messy nested string concatenations, template loops, and manual calculations for column footers. json-renderers replaces this entire imperative ritual with a single, declarative JSON config:

1. Zero String Concatenation

Instantiates native browser DOM elements (createElement) via json-to-tag, preventing XSS and memory leaks.

2. Automated Serial Numbering (#)

Prepends a 1-based sequential row counter column automatically so your backend does not need to compute row positions.

3. Right-Aligned Numeric Values

Inspects column values dynamically; numeric currencies and quantities are right-aligned following accounting guidelines.

4. Automated Total Calculations

When using table.withFooter, mathematical column totals are computed and placed in <tfoot> automatically.

How to Build It (Step-by-Step)

To render a table, define a target container in your HTML and call the render() function with your declarative schema: 

<!-- 1. Target Container in HTML -->
<div id="table-container"></div>

<!-- 2. ES Module Import & Execution -->
<script type="module">
  import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v18/min.js";

  render({
    type: "table.withFooter", // Or "table.simple"
    columns: ["item", "category", "qty", "amount"],
    data: [
      { item: "High Tensile Rope 10mm", category: "Hardware", qty: 25, amount: 3000 },
      { item: "Agri Shading Net 50%", category: "Agri", qty: 10, amount: 1250 },
      { item: "Safety Cordage Roll", category: "Hardware", qty: 15, amount: 1425 }
    ],
    targetHtmlId: "table-container",
    showLog: false
  });
</script>

Schema Parameters:

Key Type Required Description
type string Yes Use "table.withFooter" for tables with summary footers, or "table.simple" for standard tables.
columns Array<string> Yes Ordered list of keys from data objects to display as table headers and body columns.
data Array<object> Yes Array of raw JavaScript objects representing rows.
targetHtmlId string Yes The DOM element id where the rendered <table> will be mounted.
