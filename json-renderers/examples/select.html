Dropdown Select Menus

Generate standards-compliant <select> elements and option trees effortlessly from declarative JSON structures, eliminating manual HTML concatenation and string templates.

Documentation • Part 1

Why Use json-renderers Select Builds?

Form dropdown menus are among the most frequently used interface controls. Constructing them imperatively with string templates is tedious and prone to markup bugs. json-renderers handles it declaratively:

1. Standard Form Compliance

Creates clean native <select> and <option> elements that integrate directly into HTML form submissions.

2. Direct Array & Key-Value Binding

Pass array items directly. Values and visible labels are automatically structured without boilerplate loops.

3. Safe DOM Creation

Constructed via native text nodes, preventing escaping errors when values contain quotation marks, ampersands, or symbols.

4. Reactive Options Swapping

Updating options when parent dropdowns change (e.g. Country -> State -> City) takes only a single declarative render call.

Documentation • Part 2

How to Build It (Step-by-Step)

Provide a target container in your HTML and call render() with type: "select": 

<!-- 1. Target Container for generated <select> -->
<div id="select-container"></div>

<!-- 2. ES Module Import & Render -->
<script type="module">
  import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v18/min.js";

  render({
    type: "select",
    data: ["India", "United States", "United Kingdom", "Germany", "Japan", "Australia"],
    targetHtmlId: "select-container",
    showLog: false
  });
