HTML5 Autocomplete Datalists

Construct native HTML5 <datalist> elements paired with <input list="..."> for zero-dependency, ultra-lightweight autocomplete search suggestions directly from JSON arrays.

Documentation • Part 1

Why Use json-renderers Datalist Builds?

Traditional autocomplete requires heavyweight JavaScript search plugins (often 50KB+), external CSS bundles, and complex custom dropdown DOM structures. json-renderers builds native browser datalists:

1. Zero Runtime Overhead (0 KB)

Browsers already possess native autocomplete engines. json-renderers simply generates standard <option> tags into <datalist>.

2. Native Accessibility & Keyboard Support

Works out-of-the-box with screen readers and supports native Arrow keys, Enter, and Escape without custom event handlers.

3. Direct Array Source Mapping

Feed a simple string array (e.g. ["Delhi", "Mumbai", "Hyderabad"]) and get a fully wired autocomplete suggestion engine.

4. Dynamic Dictionary Swapping

Switch between different recommendation datasets instantly based on user context or preceding form field selections.

Documentation • Part 2

How to Build It (Step-by-Step)

Include an <input> with a list attribute in your HTML, prepare a container for the datalist, and call render(): 

<!-- 1. Input field paired with the datalist ID -->
<input list="cities-list" placeholder="Search cities..." />

<!-- 2. Target Container for generated <datalist> -->
<div id="datalist-container"></div>

<!-- 3. ES Module Import & Render -->
<script type="module">
  import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v18/min.js";

  render({
    type: "datalist",
    columns: [{ columnName: "cities-list" }],
    data: [
      { "cities-list": "Hyderabad" },
      { "cities-list": "Bengaluru" },
      { "cities-list": "Chennai" },
      { "cities-list": "Mumbai" },
      { "cities-list": "Pune" },
      { "cities-list": "Delhi" }
    ],
    targetHtmlId: "datalist-container",
    appendPosition: "replace",
    classToApply: "",
    showLog: false
  });
</script>

Schema Parameters:

Key Type Required Description
type string Yes Must be set to "datalist" to activate the datalist compiler.
columns Array<{ columnName: string }> Yes Specifies the target identifier matching the input's list attribute.
data Array<object | string> Yes Dataset containing suggestion entries to build as <option> items.
targetHtmlId string Yes The DOM element id where the compiled <datalist> will be injected.
appendPosition string Yes Specifies DOM insertion mode: "replace", "append", or "prepend".
