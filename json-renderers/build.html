json-renderers-build

Headless Specification Builder: From Data to JSON Tag Trees

json-renderers-build is the headless compiler of the ecosystem. It takes raw data records, column definitions, and component intentions — and translates them into an abstract JSON tag structure specifying the exact DOM hierarchy, attributes, class names, alignments, and footer calculations.

Component Builders

What builds json-renderers-build constructs

The builder contains specialized factory functions for each supported UI archetype:

Table Builder

Table Architecture

Transforms an array of records into a structured <table> specification:

  • thead: Headers with formatted column titles and serial `#` column.
  • tbody: Serialized rows, cell-level data bindings, and alignment.
  • tfoot: Automated totals and arithmetic sums for numerical columns.
Datalist Builder

Autocomplete Pairs

Generates a synchronized pair: an <input list="id"> element paired with a child <datalist> holding dynamic <option value="..."> children.

Select Builder

Dropdown Selects

Compiles data records into a native <select> element with populated <option> items, setting value attributes and readable display text.

Functional Transformation

How input becomes a JSON tag tree

Here is what happens when you call the builder. Notice how high-level intentions are translated into concrete element blueprints:

1. Input Render Request:

{
  type: "table.simple",
  columns: ["item", "qty"],
  data: [
    { item: "Rope", qty: 25 },
    { item: "Net",  qty: 10 }
  ]
}

2. Output JSON Tag Specification (compiled by json-renderers-build):

{
  tagName: "table",
  attributes: { class: "table table-striped table-bordered" },
  children: [
    {
      tagName: "thead",
      children: [
        {
          tagName: "tr",
          children: [
            { tagName: "th", text: "#", attributes: { style: "width: 50px;" } },
            { tagName: "th", text: "Item" },
            { tagName: "th", text: "Qty", attributes: { style: "text-align: right;" } }
          ]
        }
      ]
    },
    {
      tagName: "tbody",
      children: [
        {
          tagName: "tr",
          children: [
            { tagName: "td", text: "1" },
            { tagName: "td", text: "Rope" },
            { tagName: "td", text: "25", attributes: { style: "text-align: right;" } }
          ]
        },
        {
          tagName: "tr",
          children: [
            { tagName: "td", text: "2" },
            { tagName: "td", text: "Net" },
            { tagName: "td", text: "10", attributes: { style: "text-align: right;" } }
          ]
        }
      ]
    }
  ]
}
The Contract: Notice how json-renderers-build produces a pure data object. It does not create DOM nodes, attach listeners, or render to the screen. That responsibility is delegated entirely to json-to-tag.
Smart Calculations

Automated footer sums and column detection

One of the biggest struggles in building composite tables is calculating totals and aligning numbers to the right. json-renderers-build handles this automatically:

01

Numeric Type Detection

The builder samples row values. If a column contains numerical quantities or amounts, it flags the column for right-alignment and marks it eligible for summary totals.

02

Footer Sum Accumulation

When type: "table.withFooter" is selected, the builder calculates sums across all rows during its single pass, formatting the results into a dedicated <tfoot> row.

03

Row Serials Insertion

Adds an index column (#) automatically, starting at 1 and incrementing sequentially for every row.
