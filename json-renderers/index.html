Declarative DOM Orchestrator

Where Data + Columns + Type Become Native DOM

json-renderers is the place where we build JSON blueprints and mount real HTML. The client supplies the data, the story about the data, and the component type — the engine compiles and renders it instantly.

The 3 Inputs Story Explore Components
The Architecture Story

What Does the Client Supply?

To build any component, the developer only provides 3 simple, declarative inputs:

1. data
The Raw Facts

The plain business records directly from your API, database, or state store. An array of objects with zero HTML markup or styling attached. 

data: [
  { item: "Rope", qty: 25, price: 120 },
  { item: "Net",  qty: 10, price: 350 }
]
2. columns
The Story About The Data

Which fields matter to the user, how they are labeled, in what sequence, how numbers should align, and which columns need automated totals. 

columns: [
  "item", 
  "qty", 
  "price"
]
3. type
The Component Intent

What kind of component you wish to materialize from this data: a full table with footer sums, a lightweight autocomplete datalist, or a select dropdown. 

type: "table.withFooter"
// or "table.simple"
// or "datalist"
// or "select"
The Runtime Magic

Once these 3 inputs are given, json-renderers delegates the blueprint synthesis to json-renderers-build, asks @keshavsoft/json-to-tag to create the real HTML DOM nodes, and mounts them cleanly into your target element.
