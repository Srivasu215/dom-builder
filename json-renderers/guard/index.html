CDN Integration

Using guardFunc in the Browser

Import guardFunc from the jsDelivr CDN inside any native ES module script. Validate your config first to guarantee failure-free rendering: 

// Browser ES Module Integration via jsDelivr CDN
import guardFunc, { guardSpec, guardMount } from "https://cdn.jsdelivr.net/npm/json-renderers-guard/+esm";
import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v19/min.js";

const config = {
  type: "table.simple",
  targetHtmlId: "dom-render-container",
  data: [
    { itemName: "Item 01", baseUnit: "kgs" },
    { itemName: "Item 02", baseUnit: "pcs" }
  ],
  columns: [
    { columnName: "itemName" },
    { columnName: "baseUnit" }
  ],
  appendPosition: "replace",
  classToApply: "table table-striped",
  showLog: true
};

try {
  // 1. Guard intercepts & validates configuration first
  guardFunc(config);

  // 2. Render executes safely knowing inputs meet the contract
  render(config);
} catch (err) {
  // Catches missing keys or malformed structures before DOM crashes
  console.error("Guard validation error:", err.message);
}
Modular Guard

guardSpec(config)

Validates data specification only (type, data, columns, showLog). Ideal when DOM mounting is handled separately.

Modular Guard

guardMount(config)

Validates DOM mount keys only (targetHtmlId, appendPosition, classToApply).

Composite Guard

guardFunc(config)

Full pipeline sentinel that runs both guardSpec and guardMount in one unified call.
