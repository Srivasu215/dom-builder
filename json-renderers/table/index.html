Declarative Code
// 1. Import render from json-renderers CDN
import render from "https://cdn.jsdelivr.net/gh/keshavsoft/json-renderers@main/docs/dist/v18/min.js";

// 2. Define columns and data
const columns = ["item", "category", "qty", "amount"];
const data = [
  { item: "High Tensile Rope 10mm", category: "Hardware", qty: 25, amount: 3000 },
  { item: "Agri Shading Net 50%", category: "Agri", qty: 10, amount: 1250 },
  { item: "Baler Twine 400m", category: "Packaging", qty: 40, amount: 2800 },
  { item: "Safety Cordage", category: "Hardware", qty: 15, amount: 1425 }
];

// 3. Render directly into target element
render({
  type: "table.withFooter", // or simple, headerOnly, bodyOnly, footerOnly
  columns: columns,
  data: data,
  targetHtmlId: "table-container",
  showLog: true
});
Dynamic Builders Available:
  • table.withFooter: Full table with <thead>, <tbody>, and calculated <tfoot>.
  • table.simple: Standard table with header and data rows.
  • table.headerOnly: Pure table header — perfect for sticky header setups.
  • table.bodyOnly: Pure data rows — ideal for infinite scroll / pagination appending.
  • table.footerOnly: Summary / calculation footer row.
